One kind, funny fortune for a houseplant, 113 characters: "You will outgrow this pot by spring, and your keeper, who talks to you daily, will pretend it was the fertilizer." `main.py` writes that single line to `entry.txt` in the output directory, deterministically, ready for make.fun's judge — a gardener of thirty years picking the fortune that would delight the plant's keeper most.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```
